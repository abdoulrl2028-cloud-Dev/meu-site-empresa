## Features

- Responsive layout for phone, tablet, and desktop
- Mobile navigation menu
- Contact form with validation and feedback
- Scroll animations
- Semantic HTML
- No framework dependencies

## Run it locally

```bash
git clone https://github.com/abdoulrl2028-cloud-Dev/meu-site-empresa.git
cd meu-site-empresa
python -m http.server 8000
```

Open http://localhost:8000

The published site is [https://abdoulrl2028-cloud-dev.github.io/meu-site-empresa/](https://abdoulrl2028-cloud-dev.github.io/meu-site-empresa/).
